# REWIND — план робіт

## Ціль і межі

Завершити UK/EN REWIND на GitHub Pages + Supabase Free. Зберігати маршрути, API-контракти, числові ID, ролі, приватність і доступність. Архітектура та запуск описані в [README](README.md).

Активна ціль власника — довести сайт до повної готовності для користувачів: GitHub Pages і Supabase Free, UI/Figma-приймання, Auth/API, каталог TMDB, доступність та перевірений реліз. GitHub Pages + Supabase лишаються основою; інший безкоштовний hosting/edge розглядати лише якщо він реально закриває вимоги без ламання Auth/CORS. Не шукати втрачені локальні дані й не створювати порожню БД замість них. Перевірки не повинні без потреби додавати чи змінювати production-контент.

Spring Boot/MySQL/Redis/Mailpit мають окремий локальний життєвий цикл. Наявні локальні зміни й дані зберігати. Перед перенесенням різних версій файлів проводити змістовне порівняння.
