# REWIND — план робіт

## Ціль і межі

Завершити UK/EN REWIND на GitHub Pages + Supabase Free. Зберігати маршрути, API-контракти, числові ID, ролі, приватність і доступність. Архітектура та запуск описані в [README](README.md).

Поточний фокус робіт за узгодженням із власником — **Git і Supabase**: Git master/кандидат/CI та hosted Supabase API, схема, міграції, резервна копія й доступи. Не шукати втрачені локальні дані або інші джерела. Не змінювати production дані чи конфігурацію без окремого явного доручення. Інші пункти цього плану зберігаються як історія або відкладений контекст і не розширюють поточний фокус.

Spring Boot/MySQL/Redis/Mailpit мають окремий локальний життєвий цикл. Наявні локальні зміни й дані зберігати. Перед перенесенням різних версій файлів проводити змістовне порівняння.
