# Rewind diploma visual demo

The `frames` directory contains six screenshots captured from the live local Web container with headed Chromium at 1280×720 on 18.10.2026. `index.html` is a self-contained autoplay slideshow with captions and keyboard-independent controls.

This artifact is visual evidence for a diploma demo, not a claim of Figma parity or public production launch. The reproducible headed Chromium capture helper produced `rewind-diploma-demo.webm` (76,223 bytes; WebM/EBML header verified). The recording contains six 3.5-second frames and is accompanied by the self-contained slideshow for review.
