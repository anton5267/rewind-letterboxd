Journal remaining full-frame/content/locale/state scope та newsletter/phone mapping відкриті.
- `845:1679` ідентифіковано як hidden Profile Films phone collection; visibility відновлена. Owner/prototype branch та populated runtime parity відкриті. Збережені references доступні локально.
